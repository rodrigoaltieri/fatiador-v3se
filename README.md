# Fatiador V3 SE

Fatiador web para a **Creality Ender-3 V3 SE** (bico 0,4, PLA), feito para usar no iPad. Roda inteiro no navegador: abre STL, 3MF ou OBJ, fatia e baixa o `.gcode` direto para o app Arquivos.

**Abrir:** https://rodrigoaltieri.github.io/fatiador-v3se/

No iPad: Safari → Compartilhar → **Adicionar à Tela de Início** para abrir como app, inclusive sem internet.

- Perfil já calibrado para o PLA do Rodrigo (205 °C, fluxo 0,98, retração 1,2 mm, 13 mm³/s)
- Aba **Calibração** com 9 testes que geram a peça e aplicam o resultado
- Ajustes ficam no aparelho; **Exportar/Importar ajustes** leva de um aparelho para outro
- Início e fim do G-code iguais aos do perfil oficial da V3 SE no OrcaSlicer

Detalhes técnicos e pendências em [CLAUDE.md](CLAUDE.md); resultados das impressões em [docs/historico.md](docs/historico.md).
